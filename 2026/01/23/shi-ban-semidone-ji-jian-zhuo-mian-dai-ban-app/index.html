事半功倍，专注当下

一款为 Windows 用户打造的轻量级桌面待办应用。

应用简介

事半·SemiDone 是一款本地优先的 Windows 桌面待办应用：无需注册，任务与使用数据均保存在本机；既能快速记录事项，也能管理周期任务、附件、优先级与完成统计。

名字取自“事半功倍”。SemiDone 由 Semi（“一半”）与 Done（“完成”）组成，希望把未完成的事放到清晰、随手可见的位置。

  • GitHub 仓库与更新记录
  • 查看最新 Releases

当前稳定版：v5.0.1

当前稳定版为 v5.0.1（2026-07-21）。它在 5.0 的基础上修复了跨天使用时长与周统计问题，并延续以下功能：

  • 快速创建待办，支持标题、描述、优先级、截止日期与关键词搜索
  • 支持任意文件附件：拖拽或粘贴上传，单文件最大 10MB
  • 支持按日、周、月循环的周期任务，完成后自动创建下一周期
  • 任务筛选、排序、置顶与日历式完成统计
  • 明亮、深色、梦粉等主题；深色主题支持透明模式
  • 折叠为迷你条或悬浮球，支持窗口置顶与开机自启
  • 本地 JSON 存储、无需账号；支持自定义数据目录

v6.0 开发预告：液态玻璃主题

v6.0 正在开发中，重点是液态玻璃视觉与交互体验：在保留轻量、专注与本地存储原则的前提下，为设置、弹窗及控件带来更统一的玻璃质感与可调节效果。

计划加入的互动功能：

  • 🍗 加鸡腿按钮：点击即可为开发者加鸡腿，并显示已加鸡腿的数量。
  • 不限制重复点击：同一位用户可以多次点击，表达持续支持。

v6.0 尚未作为稳定版发布；实际功能与界面以正式 Release 为准。

技术与隐私

项目 说明
前端 React 18 + TypeScript + Tailwind CSS
桌面框架 Tauri 2.0 + Rust
状态管理 Zustand
数据存储 本地 JSON 文件
支持系统 Windows 10 / 11
  • 所有待办数据默认保存在本地，不依赖云端同步。
  • 不需要注册账户，打开即可使用。
  • 安装包约 3MB，启动时间小于 1 秒。
